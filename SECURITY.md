# Security policy

## Supported versions

Until 1.0, only the latest published version of each `@codecora/*` package
receives fixes.

## Reporting a vulnerability

Do **not** open a public issue for a vulnerability.

Use [GitHub Private Vulnerability Reporting](https://github.com/codecoradev/codecora-ui/security/advisories/new),
or email **hello@codecora.dev** with the subject `[CodeCora UI security]`.
Include a description, steps to reproduce, the affected package and version,
and the impact you see.

## What to expect

- Acknowledgment within 3 working days.
- An assessment and a fix plan, or a reasoned decline, within 14 days.
- Credit in the release notes if you want it.
