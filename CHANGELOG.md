# Changelog

All notable changes to this repository are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Packages are
versioned independently with [Semantic Versioning](https://semver.org/)
(0.x: minor = features, patch = fixes); per-package changelogs are generated by
changesets (`packages/*/CHANGELOG.md`).

## [Unreleased]

## [0.5.0] - 2026-11-02

`@codecora/tokens` 0.5.0 and `@codecora/memory` 0.2.0. `@codecora/ui` stays at 0.4.0, `@codecora/icons` and `@codecora/brand` at 0.1.0. Install from the GitHub Release tarballs (see the README); npm publishing is still pending (#15).

### Added

- `@codecora/tokens`: the shadcn bridge maps `--chart-1` to `--chart-5` (accent, success, warning, danger, muted text), so charts in shadcn-svelte apps follow the theme. The map is exported as `shadcnBridge`.
- `@codecora/memory`: memory browser components on `@codecora/ui`. `MemoryList` has search, tag and room filters, keyboard rows and paging; `MemoryDetail` has pin, edit and delete with confirmation; `MemoryEditor` works on its own too. They share state through `MemoryBrowser` and hide what the backend's capabilities lack (no room filter on Uteke Cloud). The client gains `roomMemories`, and `createInMemoryClient` runs the components without a server. `@codecora/ui` (^0.4.0) is now a peer dependency.
- Registry: a shadcn-svelte registry served by the playground at `/r/<item>.json`, with the `cc-theme` bridge item and four blocks (login, settings, dashboard shell, data table). `shadcn-svelte add <site>/r/<item>.json` installs them.
- Playground: a Registry page with one install command per item, and a Memory page that runs the memory browser over sample uteke-serve, Uteke Cloud and desktop backends, or a live uteke-serve.

## [0.4.0] - 2026-11-02

`@codecora/tokens` and `@codecora/ui` 0.4.0. `@codecora/memory`, `@codecora/icons` and `@codecora/brand` stay at 0.1.0. Install from the GitHub Release tarballs (see the README); npm publishing is still pending (#15).

### Added

- `@codecora/tokens`: a fifth density token, `--cc-control-py`, for the block padding of rows whose label can wrap: 0.5rem at comfortable, 0.25rem at compact.
- `@codecora/ui`: motion for the components that still cut between states, on the existing motion tokens. Tooltip, DropdownMenu, Select and Combobox fade and scale in from their trigger and out on close; CommandPalette drops in like Dialog; Accordion panels open to their measured height; the Tabs underline slides; Checkbox fills and its check springs in; Slider steps glide; ToggleGroup and Pagination ease their fill; Avatar images and Alert fade in. Under `prefers-reduced-motion` all of it is instant.

### Fixed

- `@codecora/ui`: at compact density, Checkbox, RadioGroup, Switch and Accordion rows are 32 px like every other control (they stopped at 36 to 40 px because of a fixed block padding). Comfortable is unchanged.

## [0.3.1] - 2026-11-01

`@codecora/ui` 0.3.1. `@codecora/tokens` stays at 0.3.0, `@codecora/memory`, `@codecora/icons` and `@codecora/brand` at 0.1.0. Install from the GitHub Release tarballs (see the README); npm publishing is still pending (#15).

### Changed

- Playground: the front page opens with a rail of all eleven themes, each drawn in its own theme, above a strip of live components that follow the pick; the rail is one Tab stop (arrows move, Enter applies) and keeps its names on phones. Theme tiles show a strip of their surfaces and drop their Use buttons. The toolbar triggers lead with their values ("Default (teal) · Comfortable"), theme chips show a swatch with Access notes under each, and the dashboard uses the same popovers. `/tokens` opens with an index of the theme pages, which gain previous and next links and a link into the playground; Tokens is current on them. Nav links are 44 px, and "Show the code" reads "Hide the code" when open.

### Fixed

- `@codecora/ui`: CodeBlock says "Copy failed" when the clipboard refuses, selects the code so the keyboard shortcut copies it, and announces it; before, a failed copy reset without a word.
- `@codecora/ui`: CodeBlock and Kbd turn off font ligatures, so code shows the characters as typed (`<!--` no longer renders as an arrow in themes whose mono font has ligatures).
- Playground: a saved or linked theme is applied before the first paint, so pages no longer load in the default theme and fade; the phone toolbar fits one row.

## [0.3.0] - 2026-11-01

`@codecora/tokens` and `@codecora/ui` 0.3.0. `@codecora/memory`, `@codecora/icons` and `@codecora/brand` stay at 0.1.0. Install from the GitHub Release tarballs (see the README); npm publishing is still pending (#15).

### Added

- `@codecora/tokens`: eight themes, for eleven in all. `neutral-dark` and `uteke-dark` (dark twins), `sepia` (serif reading), `contrast` (7:1 text, heavier rings and icons), `dimmed` (low-glare dark), `slab` (brutalist print: square corners, mono headings, hard offset shadows), `soft` (round corners, rounded sans, thin icons) and `neutral-cvd` (blue success and vermillion danger for red/green colour vision deficiency). Themes gain `twin`, `minText` and an optional `shadow`; `--cc-shadow-popover` and `--cc-shadow-modal` now come from the theme.
- `@codecora/tokens`: the `orange`, `indigo` and `cyan` accents, each meeting AA on every theme.
- `@codecora/tokens`: motion tokens. Durations `instant` 70, `fast` 140, `normal` 240 and `slow` 400 ms; curves `out`, `in-out`, `exit` and a `linear()` spring with a small overshoot. Under `prefers-reduced-motion` every duration is 0 ms and the spring falls back to `out`. The Tailwind preset adds the curves.
- `@codecora/ui`: Dialog, ConfirmDialog, Sheet, Popover and Toast animate out as well as in, with exits one step shorter than entries; the centred Dialog and Toast move on the spring.
- Playground: an overview at `/` with every theme side by side on real components, the token catalogue at `/tokens`, a `/motion` page with replayable enter and exit, a type and shape specimen per theme, switchers with colour swatches, shareable `?theme=&accent=&density=` links, `aria-current` navigation with a skip link, and a grouped Components index that marks the section in view.
- README: current install URLs, a quick start, the components by group, every theme and accent, and a note on Uteke Cloud.

### Changed

- The `contrast` theme uses square corners (radius 2, 4 and 6 px).

### Fixed

- `Combobox` colours its placeholder with `--cc-text-muted`; the browser default grey fell below 4.5:1.
- Playground: the Components page no longer overflows at 375 px (screen-reader text escaped the State matrix scroll box), the dashboard chart labels its days, and the Tokens page no longer claims `VisuallyHidden` is the only component.

## [0.2.0] - 2026-10-30

`@codecora/tokens` and `@codecora/ui` 0.2.0, and the first release of `@codecora/memory` (0.1.0). `@codecora/icons` and `@codecora/brand` stay at 0.1.0. Install from the GitHub Release tarballs (see the README); npm publishing is still pending (#15).

### Added

- `@codecora/tokens`: theme shape hooks (badge radius, case, tracking and font; focus-ring width and offset; selected-row marker), stacking layers (`--cc-layer-*`) and theme-aware shadows (`--cc-shadow-popover`, `--cc-shadow-modal`); a test that fails when a component reads a token the package does not emit.
- `@codecora/ui`: Checkbox (with a mixed state), Switch, RadioGroup, Combobox, Slider, FieldGroup, Card, Alert, Avatar, Progress, Separator, Kbd, Link, CodeBlock, Breadcrumb, Accordion, ToggleGroup, Pagination, Popover, DropdownMenu, CommandPalette and DataTable (sorting, selection, bulk bar, paging, loading and empty states).
- `@codecora/memory`: a `MemoryClient` over uteke-serve and Uteke Cloud (HTTP) and the Corin desktop commands (Tauri), with typed memories, documents, rooms, tags, stats, export and import, per-backend `Capabilities`, and contract tests that run against a real uteke-serve (and a Uteke Cloud stack when configured). The HTTP client refuses to send an API key over plain `http` to a remote host.
- Playground: a state matrix and props on the Components page, and a Samples page (sign in, settings, list and detail, data table, first run).

### Fixed

- The Progress bar read a duration token that does not exist, so it never animated.

### Known gaps

- The Uteke Cloud contract run (#10) is deferred until a test Cloud workspace exists.

## [0.1.0] - 2026-10-30

First release of `@codecora/tokens`, `@codecora/ui`, `@codecora/icons` and `@codecora/brand` (all 0.1.0). Not on npm yet: install the tarballs attached to the GitHub Release (see the README); publishing to npm starts once the `@codecora` scope is set up (#15).

### Added

- Planning documents: decisions D1–D12, architecture, roadmap M0–M4 with the issue map.
- Repository baseline: `AGENTS.md`, contributing guide, code of conduct, security policy, PR template and issue forms, commit hooks (`scripts/hooks/`), PR checks and review workflows.
- Dependabot for GitHub Actions.
- Monorepo tooling: bun workspaces, strict TypeScript 6, `svelte-package` + publint, vitest with Testing Library, ESLint and Prettier, changesets; `@codecora/ui` and playground skeletons.
- `@codecora/tokens`: primitive, semantic and theme tiers with the `neutral`, `uteke` and `corin` themes, `data-accent` and `data-density` modifiers, nesting per element, a Tailwind 4 preset and a shadcn-svelte bridge; WCAG AA contrast check for every theme and accent.
- Design context for the impeccable workflow: `PRODUCT.md`, a shared `DESIGN.md`, one `docs/design/<theme>.md` per theme kept in sync with the tokens by a test, and `bun run detect`.
- Playground catalogue: theme, accent and density switchers, colour roles, control states, type, radius and spacing scales, a nested-theme demo, the contrast table per theme and accent, and fixed `/themes/<name>` pages for visual snapshots.
- CI: a `Gates` workflow (lint, check, test, build, contrast, detector, pack dry run) on every PR and push to `develop` and `main`, and a `Release` workflow that publishes to npm with trusted publishing and provenance from `main`, dry run until publishing is enabled.
- `@codecora/ui`: first primitive set on bits-ui (Button, IconButton, Field, Input, Textarea, Select, Dialog, ConfirmDialog, Sheet, Tabs, Table, Badge, Toast, Tooltip, EmptyState, Skeleton, Spinner) with unit tests; a Components page in the playground and screenshots under `docs/assets/screenshots/`.
- Playground: an admin dashboard sample at `/dashboard` built from the primitives (sidebar and navigation sheet, usage summary, chart, filterable keys table, revoke flow), a shared appearance store for its pages, and its screenshots.
- `@codecora/ui`: `AppShell` and `Sidebar` (grouped navigation with brand and footer slots, collapsible on desktop, a drawer and a bottom bar of up to 5 items on narrow screens, a skip link, a per-region sidebar theme) with unit tests; the dashboard sample now uses them.
- `@codecora/ui`: error states and ConfirmDialog hardened after the impeccable critique of the primitives (see Fixed).
- `@codecora/icons`: an `Icon` wrapper that follows the theme's icon size and stroke, a curated Lucide set (`@codecora/icons/lucide`) and a Phosphor adapter (`@codecora/icons/phosphor`); an Icons page in the playground. The playground demos now take their icons from the package.
- `@codecora/brand`: marks and favicon sets for Uteke, Corin and Gatehouse as files and Svelte components (`Mark`, `Favicons`); the Uteke mark is a covecto trace of its PNG master (smaller and cleaner than the PNG), Corin stays a PNG because a trace distorted it, with the comparison in the package README; a Brand page in the playground, which now uses the Corin favicon set.

### Fixed

- `Table`: the visually hidden caption and header labels no longer widen the page on narrow screens.
- `Field` errors no longer rely on colour alone (icon and "Error:" prefix), `required` reaches the control, and invalid controls have a stronger border; `ConfirmDialog` forwards `theme`, focuses Cancel first for danger, emphasises the irreversible sentence and can require a typed name; `Button` accepts a `loadingLabel`.
- `Toaster`: a toast pauses while it is hovered or focused (WCAG 2.2.1) and resumes with at least a moment left; `Tabs`: a disabled tab has a dashed underline so it no longer reads like an unselected one; `Skeleton` pulses with opacity instead of repainting a gradient every frame; the playground nav links are 24 px tall.

### Security

- Workflows: the review access token is a step output instead of a job-wide variable, actions are pinned to commit SHAs, the message standard runs from the base branch, and the PR description check requires real content under whole `## What` / `## Why` / `## Testing` headings.
