# @codecora/icons

## 0.1.0

### Minor Changes

- d778318: First release: an `Icon` wrapper that renders any Svelte icon component at the theme's `--cc-icon-size` and `--cc-icon-stroke` (decorative by default, labelled on request), a curated Lucide set at `@codecora/icons/lucide` and a Phosphor adapter (`PhosphorIcon`, `weightForStroke`) at `@codecora/icons/phosphor`. `@lucide/svelte` and `phosphor-svelte` are optional peers.
